# Debrief scorecard

Score each capability against today's real system.

- **0 — Absent:** no shared approach exists.
- **1 — Assumed:** an approach exists in people's heads but is untested.
- **2 — Documented:** ownership and procedure are recorded.
- **3 — Rehearsed:** the capability has been tested and evidence is available.

| Capability | Score | Evidence or gap |
| --- | ---: | --- |
| User impact can be detected | | |
| Incident ownership is explicit | | |
| The feature can be safely stopped or degraded | | |
| Relevant evidence can be preserved and inspected | | |
| Access and action boundaries are enforced | | |
| Users and internal teams can be informed clearly | | |
| Recovery and verification criteria are explicit | | |
| Follow-up becomes tests, controls, or runbook changes | | |
